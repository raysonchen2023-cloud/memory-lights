# 記憶節奏燈

一個在瀏覽器裡玩的記憶小遊戲：四個彩色燈會依序亮起，記住順序後照著按一遍。每過一回合，序列就多一個燈，播放速度也會變快。

## 怎麼開始

不需要安裝任何東西，直接用瀏覽器開啟 `index.html` 即可。

## 玩法

1. 按中間的「開始」（或按空白鍵）。
2. 仔細看燈亮的順序。
3. 看到「換你了！」之後，照同樣的順序按燈。
4. 全部答對就進入下一回合；按錯一個遊戲就結束。

## 操作

| 動作 | 滑鼠 | 鍵盤 |
|---|---|---|
| 左上（綠） | 點擊 | `Q` |
| 右上（紅） | 點擊 | `W` |
| 左下（黃） | 點擊 | `A` |
| 右下（藍） | 點擊 | `S` |
| 開始／重來 | 點擊中間按鈕 | 空白鍵 |

## 紀錄

最高紀錄是你完成的回合數，會存在瀏覽器的 `localStorage`，重新整理頁面後仍然保留。清除瀏覽器的網站資料會讓紀錄歸零。
